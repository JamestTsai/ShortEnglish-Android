## 4. AndroidManifest.xml 關鍵安全配置

1. **禁用 WorkManager 自動初始化**：在 Android 14/15/16 審核環境下，某些自動初始化程式會觸發 `SecurityException` 導致啟動閃退，必須於清單中宣告移除。
2. **軟鍵盤適應**：加入 `android:windowSoftInputMode="adjustResize"`，防止輸入跳轉課號或搜尋時覆蓋操作列。

## 5. 資料模型與資產管理 (SentenceModel / SentenceRepository)

### (1) 資料欄位定義 (`SentenceModel.kt`)
語料庫每筆資料包含以下 10 個核心欄位：
- `id` (Int): 1 到 2500 之題號
- `en` (String): 核心道地英文短句（全小於等於 6 個單字）
- `zh` (String): 簡明精準道地中文翻譯（禁止機翻硬拗）
- `wordCount` (Int): 單字個數
- `category` (String): 情境分類標籤（如 `[🛑 拒絕終止]`、`[💼 職場交際]` 等）
- `spkA` (String): 情境示範對話 A 句
- `spkB` (String): 情境示範對話 B 句
- `note` (String): 文化意涵、語用語法解析
- `litTrapZh` (String): 測驗模式一專用：中文「直譯陷阱題」干擾項
- `chinglishTrapEn` (String): 測驗模式二專用：中式英文 Chinglish 干擾項

### (2) 資料庫操作 (`SentenceRepository.kt`)
1. **JSON 載入與關聯快取**：從 `context.assets.open("sentences_2500.json")` 高速反序列化為記憶體中的 `itemsById: Map<Int, SentenceItem>`。
2. **搜尋與過濾**：
   - 支援依類別分類篩選。
   - 搜尋關鍵字支援同時比對英文、中文與題號數字。
3. **收藏紀錄持久化**：
   - 使用 `SharedPreferences` 儲存鍵值 `bm_{id}`。
   - 支援 `toggleBookmark(id)`、`getBookmarkedIds()`、批次刪除 `removeBookmarks(ids)`。
4. **錯題紀錄持久化**：
   - 錯題鍵值 `wrong_m1_{id}` 與 `wrong_m2_{id}`。
   - 答錯時自動登記，並支援在標記頁面多選勾選批次清除 `removeWrongs(ids)`。
5. **雙模式陷阱題目自動產生器**：
   - `generateQuizMode1(targetId)`: 隨機選題，組裝【正確中文】+【字面直譯陷阱】+【隨機同類或異類干擾項 x2】，並隨機打散選項順序。
   - `generateQuizMode2(targetId)`: 組裝【道地正確英文】+【Chinglish 中式直譯陷阱】+【隨機英文干擾項 x2】。

## 6. 原生文字轉語音引擎 (TtsManager.kt)

封裝 Android 原生 `TextToSpeech`：
1. **初始化與語言綁定**：實作 `OnInitListener`，設定語言為 `Locale.US`。
2. **單句朗讀**：`speak(text: String, slow: Boolean = false)`，語速設為 1.0f。
3. **情境對話連續發音**：
   - `speakDialogue(spkA: String, spkB: String)`
   - 提取角色冒號後的句子，發音完 A 句後插入 `playSilentUtterance(400L, QUEUE_ADD)` 停頓 400 毫秒，隨即發音 B 句，模擬真實對話自然流暢節奏。
4. **生命週期控制**：於 `MainActivity` 之 `onStop` 呼叫 `stop()`，於 `onDestroy` 呼叫 `shutdown()` 防止記憶體洩漏。

## 8. 核心畫面一：課本式研讀介面 (TextbookScreen.kt)

   - **獨立一行之進度標籤**：`第 N / 2500 課 (#N)`（單獨一行清楚呈現，避免與其他按鈕擠壓）
2. **左右滑動手勢切換 (Horizontal Swipe Gesture)**：
   - 在卡片區加入 `pointerInput(Unit) { detectHorizontalDragGestures { ... } }`。
   - 向左滑動超過 50dp 自動切換至「下一課」，向右滑動超過 50dp 自動切換至「上一課」。
3. **核心短句展示**：

4. **發音與收藏按鈕（並列同列，移除慢速與掌握）**：

   - **全面移除 `[🐢 慢速]` 及 `[標記掌握]`，並移除卡片底部原有的獨立操作橫列，讓介面乾淨俐落**。
5. **道地核心釋義卡片**：
   - 深藍沉穩底色 (`#172554`) 搭配邊框，顯示最直觀、簡練的中文釋義。
6. **經典生活對話示範卡片**：
   - 展示 A/B 角色真實日常對話。
   - 右上角配置 `[🔊 朗讀對話]` 按鈕，點擊由 TTS 連續朗讀。

## 9. 核心畫面二：雙重陷阱深度測驗系統 (QuizScreen.kt)

### 測驗系統的核心靈魂在於「精準戳中盲點」：
1. **模式一：測驗(英) —— 英文出題，中文選答**：
   - 題目顯示地道英文短句。
   - 四個選項中必定包含「中式字面直譯陷阱題」（例如 `Enough is enough` 陷阱項為「足夠的就是足夠」），訓練使用者擺脫逐字直譯陋習。
2. **模式二：測驗(中) —— 中文出題，英文選答**：
   - 題目顯示中文情境。
   - 選項中包含常見 Chinglish 陷阱（例如「適可而止」之 Chinglish 陷阱項為 `Stop here immediately` 或 `Enough is plenty`），訓練使用者選出母語者直覺短句。
3. **回到上一階按鈕**：
   - 頂部緊湊工具列左側提供 `[◀ 回到上一階]`。
   - 在「中文題 (模式二)」點擊時回到「英文題 (模式一)」，在「英文題 (模式一)」點擊時回到「課本研讀」。
4. **作答回饋與色彩哲學**：
   - 選項背景色絕不用刺眼大紅大綠！
   - **正解選項**：淡雅薄荷綠底色 (`#DCFCE7`) + 深綠色文字 (`#14532D`) + 綠邊框。
   - **玩家選錯項目**：淡粉玫瑰紅底色 (`#FEE2E2`) + 深暗紅文字 (`#7F1D1D`) + 紅邊框。

5. **深度剖析展開專區**：
   - 作答完畢後，卡片下方即時列出四個選項的深入剖析（標明 `✅ 正解原因` 與 `❌ 各陷阱的中式直譯破綻`）。

## 13. 編譯、打包與 Google Play Release 簽名流程

### (1) 清理與編譯 APK (用於本機快速測試安裝)
```bash
./gradlew.bat assembleRelease
# 產出路徑：app/build/outputs/apk/release/app-release.apk (約 3.3 MB)
```

### (2) 清理與編譯 Google Play 上架專用 AAB (Android App Bundle)
```bash
./gradlew.bat bundleRelease
# 產出路徑：app/build/outputs/bundle/release/app-release.aab (約 6.7 MB)
```
